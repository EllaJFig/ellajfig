**Computer Science & Geography student at Wilfrid Laurier University** building data and machine learning projects, with a growing interest in geospatial analytics.

---

## 🔭 What I'm working on

**GO Transit Intelligence Dashboard**: a real-time transit analytics platform that ingests live GO Transit feeds, stores delay data in a time-series database, and trains a machine learning model to predict delays with confidence intervals.

- Live data pipeline polling GTFS-Realtime feeds with validation and deduplication
- TimescaleDB for time-series storage, Redis for caching
- LightGBM quantile regression joined with weather features (model in progress)
- FastAPI backend and an interactive Next.js + Leaflet map

[View the project](https://github.com/EllaJFig/transit-dashboard)
